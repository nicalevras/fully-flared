## Preview readiness checklist

Only a real Cloudflare preview can verify these. Nothing here deploys, and the
remote D1 is recreated first because migrations were edited in place.

Before the first deploy:

- Apply the migrations to the recreated remote D1 with `npm --prefix web run migrate:remote`, then deploy (SEC-M6).
- Run `validate-deploy.mjs` with `--env` and confirm the required secrets exist with `wrangler secret list` (SEC-L16).
- Fill the rate-limiter namespace id, and confirm the account is on Workers Paid.

Preview checks, each with the result to expect:

1. **Queues.** Send, consume, retry with `delaySeconds`, and dead-letter on `max_retries`. The catalogue drains from empty, and the DLQ consumer logs.
2. **KV timing.** Reference propagation and the one write per second per key limit. A steady stream of `catalog_ref_mismatch` means the pacing or propagation assumption is wrong.
3. **Workers Cache.** Purge and tag invalidation after an edit and a delete, the cold cache after the first deploy (P-16), and billed invocations per page view (CAT-10).
4. **Rate limiter.** Namespace id, limits, 429 and `Retry-After`.
5. **Durable Objects.** Inventory, admission and realtime under real isolation; an unreachable admission controller backs settlement off for 60 seconds.
6. **Stripe test mode.** Webhook signature on the Workers runtime, a dispute with no PaymentIntent (MONEY-03), the refund guard, and a full checkout from cart to stock decrement and reconcile, plus an abandoned checkout releasing its hold.
7. **Auth and CSRF.** Sign-in from a browser and from a script, the 2FA flow, and `/admin` redirects per role.
8. **Media.** The R2 binding, `immutable` headers on `/media/$key`, and image variants.
9. **Cron triggers.** The `*/15` tick fires, maintenance stays in budget, and `verifyChangedReferences` runs. Preview configures no crons (SEC-L17), so enable them for this check.
10. **Headers.** HSTS and the security headers on the real HTTPS origin.
11. **Soak.** After 24 hours, no `public_storefront_failed`, `catalog_build_failed` or unexpected `catalog_ref_mismatch` in the logs ([SOAK.md](SOAK.md)); measure CPU per product render (P-18).
